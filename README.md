#  Simple Bookmarks Web Page

A beginner-friendly web development project built using **HTML, CSS, and JavaScript**.
This project displays a simple bookmarks page with links to popular websites.

## 🚀 Features

* 📌 List of useful website bookmarks
* 🎨 Clean and simple user interface
* ⚡ Fast and lightweight
* 🔗 External links to websites

* JavaScript
